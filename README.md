# site-coffee-chamber-amman

Website for The Coffee Chamber, a café at The St. Regis Amman, Fifth Circle, Amman, Jordan.

- **Preview:** https://labsuncut.github.io/site-coffee-chamber-amman/
- **Intake issue:** https://github.com/labsuncut/ops/issues/2

## Where to change things

| To change | Edit |
| --- | --- |
| Menu items and prices | `assets/js/menu.js` |
| Page words (English and Arabic) | `TEXT` in `assets/js/site.js` |
| Opening hours, WhatsApp number | `SETTINGS` at the top of `assets/js/site.js` |
| Colours and fonts | top of `assets/css/site.css` |
| Photos | `assets/img/`, and the gallery section of `index.html` |
